## 1. Data Provenance Hierarchy & Typing

All data entities in FTP 2.0 are tagged with an explicit provenance level:

```
[ RAW ] ───────► [ OBSERVED ] ───────► [ INTERPRETED ] ───────► [ INFERRED ] ───────► [ VALIDATED ]
Level 0            Level 1                Level 2                 Level 3               Level 4
Direct bytes       Measured metrics       Deterministic rules     Model syntheses       Participant "RESONATES"
```

### Provenance Tier Definitions:
* **`RAW` (Level 0):** Unprocessed sensory inputs (e.g., base64 scan buffer, audio WAV PCM, raw keystroke records).
* **`OBSERVED` (Level 1):** Measured, quantifiable features (e.g., OCR transcript string, keystroke latencies in milliseconds, word counts).
* **`INTERPRETED` (Level 2):** Deterministic algorithmic classifications (e.g., Navarasa lexicon match, VADER polarity float, profanity regex hit).
* **`INFERRED` (Level 3):** Probabilistic qualitative projections generated by AI or heuristic models (e.g., 27 qualitative fortune readings, behavioral hesitation archetypes).
* **`VALIDATED` (Level 4):** Explicit participant endorsement. **Strict Invariant:** `VALIDATED` denotes *solely* that the participant marked `"RESONATES"`. It does **not** assert ground psychological or biographical truth.
